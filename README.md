# ♟️ Rating & Stats Mobile Widget Concept for Chess.com

A sleek, modern mobile widget concept designed to complement Chess.com's existing widget lineup (Daily Chess & Streaks) by bringing live competitive stats directly to the home screen.

---

## 🎯 Proposed Formats & Features

### 1. 🟩 Small Widget (2x2) — Live Overview
* Displays real-time Rapid, Blitz, and Bullet ratings in a compact green card matching Chess.com's brand identity.
* Features player avatar and username header.

### 2. ⬛ Medium Widget (4x2) — Detailed Profile & Fast Play
* Full player overview with distinct rating columns for Rapid, Blitz, and Bullet.
* Quick launch button for fast matchmaking directly from the home screen.

---

## 🛠️ Proof-of-Concept Implementation
Built using HTML, CSS, and Vanilla JavaScript fetching live data from the official **Chess.com Public API**.
